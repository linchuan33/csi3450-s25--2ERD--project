# Tiny College TFBS Center Web Application for Group Project 2ERD

## Overview
This web application is designed to manage vehicle reservations, maintenance, and reporting for the Travel Far But Slowly (TFBS) Center at Tiny College. It provides a user-friendly interface for TFBS Center employees to handle various operations efficiently.

## Features
- **Reservation Form**: Allows employees to enter and submit new vehicle reservations.
- **View Reservations**: Displays existing reservations with options to cancel or checkout.
- **Vehicle Status**: Shows the current status of all vehicles.
- **Maintenance**: Initiates and manages vehicle maintenance processes.
- **Parts Management**: Tracks parts inventory and allows reordering.
- **Reports**: Generates monthly reports on mileage, fees, parts usage, and maintenance.

## Technologies Used
- **HTML**: For the structure of the web application.
- **CSS**: For styling and layout.
- **JavaScript**: Placeholder for future dynamic interactions (scripts.js).

## Future Enhancements

- **User Authentication**: Implement login functionality for secure access.
- **Responsive Design**: Ensure the application is mobile-friendly.
